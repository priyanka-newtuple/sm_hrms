Introducing **What's New** — an in-app changelog rendered straight from MDX files.

![In-app changelog page](https://i.ibb.co/NRnbrjF/image.png)

- **MDX-authored** — drop a `.mdx` file in `/changelogs` and it appears automatically, newest first
- **Per-org visibility** — hidden by default; enable under Settings → Display → What's New
- **Rich content** — Markdown plus interactive components like accordions
