Introducing **Agent Mode** — a dedicated assistant workspace where conversation and UI work together in one place.

- **Full-screen workflow** — open Agent Mode from the main app navigation and work in a larger, focused assistant surface instead of a narrow sidebar
- **Live canvas rendering** — ask for boards, lists, calendars, tables, dashboards, and other supported views, then open them directly beside the conversation
- **Built-in system agent** — use a locked assistant configuration with the platform tools needed to inspect data, answer questions, and take actions across the app
- **Session history** — reopen previous chats and restore the canvas from the thread so the workspace comes back with useful context intact
- **Better interaction model** — get a conversation history rail, central chat panel, resizable canvas area, and follow-up prompts that keep the workflow moving
- **Access control** — only show the `/agent` route to users who are allowed to use Agent Mode
