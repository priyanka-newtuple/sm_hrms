---
title: "HRMS project and allocation approvals"
date: "2026-09-28"
tags: ["Feature"]
description: "Manage project changes and staffing allocations through assigned approvals."
---

HRMS now includes Projects, with a shared workflow view for project and allocation requests.

- Create projects with a customer, Project Manager, Delivery Manager and independent approver.
- Review proposed changes while approved project values remain in effect.
- Preview employee capacity by date and route allocation requests to the assigned approver.
- Complete approvals from the workflow drawer or find pending decisions in My Work.
- Keep commercial fields restricted to authorized roles and assigned project managers.
- Resume interrupted operations without creating duplicate requests.
