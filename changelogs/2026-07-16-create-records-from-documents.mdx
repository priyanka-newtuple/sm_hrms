---
title: "Create records from uploaded documents"
description: "Create-entity flows can now start from a document upload."
date: "2026-07-16"
tags: ["Feature", "AI"]
---

You can now upload a document while creating a record and let agent processing initialize the entity from that file.

- Added document upload support to create-entity dialogs in pipeline and records flows
- Connected uploads to the existing agent-processing path so a file can create the record before the normal form flow continues
- Added backend support for unattached uploads, processing status polling, and returning the created entity back into the UI
