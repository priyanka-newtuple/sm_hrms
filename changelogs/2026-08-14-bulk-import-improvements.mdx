The bulk import experience gets a major upgrade with a new review UI and support for parent record mapping.

- **Modernized review drawer** — a new bulk import review drawer provides a cleaner interface for reviewing and approving AI-extracted records before they're committed
- **Parent record mapping** — bulk imports now support mapping parent relationships, letting you create linked entities in a single import session
- **Agent-powered extraction** — the extraction pipeline has been refined to use a single agent per job for more consistent results
