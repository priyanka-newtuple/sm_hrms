The Pipeline view gets bulk entity actions on the Kanban board, plus fixes for rendering and custom field selection.

- **Bulk entity actions on Kanban** — select multiple entities on the board and perform bulk actions like status transitions or assignment
- **Edit actions bar** — a streamlined edit actions bar replaces the old debounced callback pattern for smoother inline editing
- **Pipeline board render fix** — repaired board rendering issues and restored the agent all-tools UI
- **Custom fields in pipeline table** — the pipeline list table now correctly fetches and displays custom fields based on user selection
