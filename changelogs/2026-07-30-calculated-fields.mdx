Build dynamic calculated fields and fixed-grid cell formulas directly in your form schemas — no code required.

- **Calculated fields** — define formula expressions that compute values from other fields, with full support for arithmetic, conditionals, and string operations
- **Fixed-grid cell formulas** — build spreadsheet-style grids where individual cells reference other cells, enabling complex dependent calculations across rows and columns
- **Backend evaluation engine** — formulas are evaluated server-side for consistency and security, with a golden test suite for validation
- **Visual builder** — configure formulas through a structured editor in the form config UI, with JSON export and import support
