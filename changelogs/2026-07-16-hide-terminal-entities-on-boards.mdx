title: "Hide terminal entities on pipeline boards"
description: "Pipeline boards can now hide terminal-state entities by default."
date: "2026-07-16"
tags: ["Feature", "UI"]
---

Pipeline boards can now hide entities that have already reached a terminal state, which keeps everyday board views focused on active work.

- Added an org-wide display setting for hiding terminal entities by default
- Added a board-level toggle so users can quickly show or hide terminal rows in context
- Introduced shared frontend wiring so the preference stays consistent across pipeline surfaces
