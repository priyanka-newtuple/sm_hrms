Connect remote MCP servers and browse platform-managed tools from a dedicated catalog.

- **GitHub MCP server** — connect a GitHub MCP server directly from the Connectors tab with OAuth-based authentication
- **Browse & filter MCP tools** — the Agents tab now lets you browse and filter platform-managed MCP tools by connector, capability, and package
- **MCP app catalog** — a catalog of remote MCP apps is available in Settings → Connectors, with cards showing available integrations
- **Remote MCP callback page** — OAuth callback handling for remote MCP servers is now wired into the app
