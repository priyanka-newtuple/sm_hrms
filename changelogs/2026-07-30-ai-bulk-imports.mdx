Import records in bulk from files — with AI assistance for extraction, mapping, and validation.

- **File-driven imports** — upload spreadsheets, documents, or mixed file types and let the system extract entity data automatically
- **AI-assisted mapping** — the platform suggests how uploaded data maps to your entity fields and form schemas, reducing manual setup
- **File type provisioning** — default file types are backfilled for existing organizations so imports work out of the box
- **Resumable sessions** — file selections are retained across navigation so you don't lose your import draft if you switch contexts
- **Bulk import module** — a dedicated backend module with controller, manager, and models for handling large-scale entity creation from files
