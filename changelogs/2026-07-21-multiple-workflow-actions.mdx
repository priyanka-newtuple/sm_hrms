title: "Multiple actions per workflow state"
description: "Chain several actions on one state, re-run the whole chain or just one, and see each action's real name."

Workflow states can now run **more than one action in sequence** instead of just one, e.g. call a webhook, then send an email, then run an agent, all from the same state.

- **Ordered action chains**: add, reorder, and remove multiple actions per state in the workflow editor.
- **Re-run the whole chain, or just one action**: the re-run control lets you replay everything from the start, or isolate and re-run a single action without touching the rest.
- **Real names, not generic labels**: the re-run menu and activity log now show the actual connector, email template, agent, or schedule an action uses (e.g. "OpenWeather") instead of a generic type like "Webhook Http" repeated for every action.
- **Chain position in the activity log**: each action event shows its place in the chain, e.g. `(2/3)`, plus whether a failure stopped or skipped the rest of the chain.
