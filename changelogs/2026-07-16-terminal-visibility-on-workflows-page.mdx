The Workflows page now lets you control whether terminal-state entities appear in the aggregated workflows list, not just inside individual pipeline views.

- Added the terminal visibility toggle to the Workflows list widget
- Reused the same hide/show behavior already used by pipeline boards
- Keeps cross-workflow browsing cleaner when teams want completed or terminal work out of the main list
